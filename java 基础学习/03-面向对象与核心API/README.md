# 阶段 2：面向对象 & 核心 API — Demo 目录

> 每个子目录包含 **可运行的 Java 示例** + **README 解析**。建议按编号顺序学习。

## 目录结构

| 编号 | 目录 | 内容 |
|-----|------|------|
| 01 | [01-面向对象](./01-面向对象/) | 类与对象、封装、继承、多态、抽象类、接口 |
| 02 | [02-异常处理](./02-异常处理/) | try-catch、受检/非受检异常、自定义异常 |
| 03 | [03-集合框架](./03-集合框架/) | List、Set、Map、遍历与常用操作 |
| 04 | [04-泛型](./04-泛型/) | 泛型类/方法、通配符、类型擦除 |
| 05 | [05-IO与文件](./05-IO与文件/) | 字节流/字符流、NIO.2、try-with-resources |
| 06 | [06-实践练习](./06-实践练习/) | 学生管理系统、CSV 解析、LRU Cache |

## 如何运行

进入任意 demo 目录，编译并运行：

```bash
cd "01-面向对象"
javac OOPDemo.java
java OOPDemo
```

> 前提：已完成阶段 1，JDK 17+ 可用。

## 学习建议

1. **OOP 是核心**：阶段 2 前半部分（01~02）打基础，03 集合是日常开发用得最多的 API。
2. **边学边写**：每看完一个 demo，尝试自己改类名、加字段、加方法。
3. **对比 TS/JS**：README 里有前端类比，帮助理解接口 vs 抽象类、Map vs Object 等。
4. **完成 06 实践练习**：三个项目分别覆盖 OOP+集合、IO、泛型+数据结构。
