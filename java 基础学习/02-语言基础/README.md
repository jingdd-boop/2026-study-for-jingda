## 如何运行

进入任意 demo 目录，编译并运行：

```bash
cd "01-数据类型与变量"
javac DataTypesDemo.java
java DataTypesDemo
```

> 前提：已安装 JDK 17+，终端执行 `java -version` 可看到版本号。

## 学习建议

1. **先读 README，再看代码**：README 讲概念，代码里有行内注释。
2. **自己改一改**：比如把 `int age = 25` 改成其他值，观察输出变化。
3. **对比 JS**：每个 README 都有前端类比，帮你快速建立联系。
4. **完成 08 实践练习**：把前面学的语法串起来。
