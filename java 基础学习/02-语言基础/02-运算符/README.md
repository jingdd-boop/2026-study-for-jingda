# 02 - 运算符

## 运算符分类

### 1. 算术运算符

| 运算符 | 含义 | 示例 |
|-------|------|------|
| `+ - * /` | 加减乘除 | `10 / 3 = 3`（整数除法截断小数） |
| `%` | 取余 | `10 % 3 = 1` |
| `++` `--` | 自增自减 | `i++` 先用后加，`++i` 先加后用 |

### 2. 比较运算符

返回 `boolean`：`==` `!=` `>` `<` `>=` `<=`

> **注意**：比较 String 不能用 `==`，要用 `.equals()`（见 06 目录）。

### 3. 逻辑运算符

| 运算符 | 含义 | 短路 |
|-------|------|------|
| `&&` | 与 | 左边 false 时不算右边 |
| `\|\|` | 或 | 左边 true 时不算右边 |
| `!` | 非 | — |

### 4. 赋值运算符

`=` `+=` `-=` `*=` `/=` `%=` — 和 JS 一样。

### 5. 三元运算符

```java
String result = score >= 60 ? "及格" : "不及格";
// 等价于 JS: const result = score >= 60 ? "及格" : "不及格"
```

## 与 JavaScript 对比

- 大部分运算符和 JS 相同
- **整数除法**：Java 中 `10 / 3 = 3`（JS 中 `10 / 3 = 3.333...`）
- 要得到小数结果：`10.0 / 3` 或 `(double) 10 / 3`

## 运行

javac OperatorsDemo.java
