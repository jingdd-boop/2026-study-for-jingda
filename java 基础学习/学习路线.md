# Java 全栈学习路线（前端转全栈版）

> 面向有前端经验（HTML / CSS / JavaScript / 框架）的开发者，系统掌握 Java 后端与全栈开发能力。

---

## 一、学习前准备

### 1.1 心态与目标

| 前端已有能力 | 转全栈时的迁移价值 |
|-------------|-------------------|
| HTTP / REST API 调用 | 理解前后端交互协议，后端设计 API 更自然 |
| 异步编程（Promise / async） | 理解 Java 多线程、CompletableFuture |
| npm / 包管理 | 类比 Maven / Gradle 依赖管理 |
| TypeScript 类型系统 | 类比 Java 强类型，上手更快 |
| 组件化思维 | 类比 Spring 的 IoC / 依赖注入 |

**建议目标**：先掌握 Java 语言与面向对象，再进入 Spring Boot 后端开发，最后打通数据库与部署，形成完整全栈闭环。

### 1.2 环境搭建

- **JDK**：安装 JDK 17 或 JDK 21（LTS 版本，企业主流）
- **IDE**：IntelliJ IDEA Community（免费）或 Ultimate
- **构建工具**：Maven 或 Gradle（建议先学 Maven）
- **版本管理**：Git（你已有经验，继续沿用）

```bash
# 验证安装
java -version
javac -version
mvn -version
```

> **为什么 Demo 要先 `javac` 再 `java`？** Java 是编译型语言：`javac` 把 `.java` 编译成 `.class` 字节码，`java` 启动 JVM 执行字节码。详见 [项目根目录 README](../README.md#为什么运行-java-要先-javac-再-java)。

## 三、各阶段详细内容

### 阶段 0：环境与工具（约 1 周）

**学习目标**：能创建、编译、运行 Java 项目，熟悉 IDE 基本操作。

| 主题 | 要点 | 前端类比 |
|-----|------|---------|
| JDK / JRE / JVM | 三者区别与关系 | Node.js runtime vs 浏览器 |
| 项目结构 | `src/main/java`、`pom.xml` | `src/` + `package.json` |
| Maven 基础 | 依赖、生命周期、仓库 | npm scripts + node_modules |
| IDEA 快捷键 | 运行、调试、重构、跳转 | VS Code / Cursor 快捷键 |

**实践任务**：
- [ ] 用 IDEA 创建 Maven 项目，写 Hello World
- [ ] 配置 Git，提交第一个 Java 项目

### 阶段 1：Java 语言基础（约 2~3 周）

**学习目标**：掌握 Java 语法，能独立编写小程序。

#### 1.1 基础语法

- 数据类型：`int`、`long`、`double`、`boolean`、`char`、`String`
- 变量与常量：`final` 关键字
- 运算符与表达式
- 流程控制：`if/else`、`switch`、循环（`for`、`while`、`do-while`）
- 数组与多维数组

> **对比 JS**：Java 是强类型，所有变量必须声明类型；没有 `var`/`let`/`const` 的灵活度，但类型安全更高。

#### 1.2 方法（函数）

- 方法定义、参数、返回值
- 方法重载（Overload）
- 可变参数 `String... args`
- 值传递机制

#### 1.3 常用类

- `String`：不可变、常用方法、`StringBuilder` / `StringBuffer`
- 包装类：`Integer`、`Double` 等，自动装箱拆箱
- 日期时间：`LocalDate`、`LocalDateTime`（Java 8+，替代旧 `Date`）

**实践任务**：
- [ ] 控制台计算器（四则运算）
- [ ] 猜数字游戏
- [ ] 字符串处理小工具（反转、统计词频）

---

### 阶段 2：面向对象 & 核心 API（约 2~3 周）

**学习目标**：理解 OOP 思想，熟练使用 Java 集合与 IO。

#### 2.1 面向对象（OOP）

| 概念 | 说明 | 前端类比 |
|-----|------|---------|
| 类与对象 | 蓝图与实例 | Class 组件 vs 组件实例 |
| 封装 | private 字段 + getter/setter | 模块私有状态 |
| 继承 | `extends`，单继承 | class extends |
| 多态 | 父类引用指向子类对象 | 接口多实现 |
| 抽象类 | `abstract`，可有实现 | 抽象基类 |
| 接口 | `interface`，多实现 | TypeScript interface |

- 构造方法、构造器重载
- `this` 与 `super`
- 静态成员：`static` 变量与方法
- 内部类（了解即可）

#### 2.2 异常处理

- `try-catch-finally`
- 受检异常 vs 非受检异常
- 自定义异常
- 最佳实践：不要吞异常、日志记录

#### 2.3 集合框架（重点）

```
Collection
├── List（有序可重复）
│   ├── ArrayList    ← 最常用，查快
│   └── LinkedList   ← 增删快
├── Set（无序不重复）
│   ├── HashSet
│   └── TreeSet      ← 有序
└── Queue
    └── PriorityQueue

Map（键值对）
├── HashMap          ← 最常用
├── LinkedHashMap
└── TreeMap
```

> **对比 JS**：`ArrayList` ≈ `Array`，`HashMap` ≈ `Object` / `Map`。

#### 2.4 泛型

- 泛型类、泛型方法
- 通配符：`? extends T`、`? super T`
- 类型擦除（了解）

#### 2.5 IO 与文件

- 字节流 / 字符流
- `File`、`Path`（NIO.2）
- try-with-resources（自动关闭资源）

**实践任务**：
- [ ] 学生管理系统（控制台版，CRUD + 集合）
- [ ] 文件读写：日志分析、CSV 解析
- [ ] 实现一个简单的 LRU Cache

### 阶段 3：Java 进阶（约 2 周）

**学习目标**：掌握并发、Lambda、Stream 等现代 Java 特性。

#### 3.1 Lambda 与函数式接口

```java
// 前端箭头函数类比
list.forEach(item -> System.out.println(item));

// 常见函数式接口
// Predicate<T>  — 判断
// Function<T,R>   — 转换
// Consumer<T>     — 消费
// Supplier<T>     — 供给
```

#### 3.2 Stream API

- `map`、`filter`、`reduce`、`collect`
- 中间操作 vs 终端操作
- 并行流（了解）

> **对比 JS**：Stream ≈ `Array.map/filter/reduce` 链式调用。

#### 3.3 多线程基础

- 创建线程：`Thread`、`Runnable`
- 线程池：`ExecutorService`
- 同步：`synchronized`、`Lock`
- 并发集合：`ConcurrentHashMap`
- `CompletableFuture`（异步编程，类比 Promise）

#### 3.4 反射与注解（了解）

- 反射基本用法
- 常用注解：`@Override`、`@Deprecated`、自定义注解
- 为 Spring 学习打基础

#### 3.5 单元测试

- JUnit 5 基础
- 断言、`@Test`、`@BeforeEach`
- Mock 概念（Mockito 入门）

**实践任务**：
- [ ] 用 Stream 重构阶段 2 的学生管理系统
- [ ] 多线程下载器（模拟）
- [ ] 为已有代码编写 JUnit 测试

---

### 阶段 4：数据库 & SQL（约 2 周）

**学习目标**：能设计表结构、编写 SQL，并用 Java 操作数据库。

#### 4.1 关系型数据库基础

- MySQL 安装与基本操作
- 数据类型、主键、外键、索引
- CRUD：`SELECT`、`INSERT`、`UPDATE`、`DELETE`
- 多表查询：`JOIN`
- 聚合：`GROUP BY`、`HAVING`
- 事务：ACID 概念

#### 4.2 JDBC

- 连接数据库、PreparedStatement
- 结果集处理
- 连接池概念（HikariCP）

#### 4.3 ORM 入门

- MyBatis 或 JPA/Hibernate 二选一入门
- 推荐路径：**先 JDBC 理解原理 → 再学 MyBatis-Plus 或 Spring Data JPA**

> **对比前端**：SQL 查询 ≈ 直接调 API；ORM ≈ 封装好的 SDK / 数据层抽象。

**实践任务**：
- [ ] 设计博客/待办事项数据库表
- [ ] JDBC 实现 CRUD
- [ ] 用 MyBatis-Plus 重写 CRUD

---

### 阶段 5：Spring Boot 后端（约 3~4 周）

**学习目标**：能独立搭建 RESTful API 后端服务。

#### 5.1 Spring 核心概念

| 概念 | 说明 | 前端类比 |
|-----|------|---------|
| IoC 容器 | 对象创建交给框架 | 依赖注入 / DI 容器 |
| DI | 依赖注入 | React Context / 注入 props |
| AOP | 面向切面 | 中间件 / 拦截器 |
| Bean | 容器管理的对象 | 单例服务模块 |

#### 5.2 Spring Boot 快速入门

- 项目创建：Spring Initializr（https://start.spring.io）
- 核心注解：
  - `@SpringBootApplication`
  - `@RestController` / `@Controller`
  - `@Service` / `@Repository`
  - `@Autowired`
  - `@RequestMapping` / `@GetMapping` / `@PostMapping` 等
- 配置文件：`application.yml`
- 热部署：spring-boot-devtools

#### 5.3 RESTful API 设计

- HTTP 方法语义：GET / POST / PUT / DELETE
- 统一响应格式
- 参数校验：`@Valid`、`@NotNull` 等
- 全局异常处理：`@ControllerAdvice`
- 跨域 CORS 配置（前后端联调必备）

> **这是你前端经验的最大优势区**：你天天调 API，现在换到「设计 API 的一方」。

#### 5.4 数据访问层

- Spring Data JPA 或 MyBatis-Plus 集成
- 分页查询
- 事务管理：`@Transactional`

#### 5.5 常用中间件（入门）

- Redis：缓存、Session
- 日志：SLF4J + Logback

**实践任务**：
- [ ] 待办事项 API（CRUD + 分页）
- [ ] 用户注册/登录（JWT 认证）
- [ ] 用 Postman / Apifox 测试所有接口

### 阶段 6：全栈联调 & 项目实战（约 4~6 周）

**学习目标**：完成一个前后端分离的全栈项目，打通开发到部署流程。

#### 6.1 推荐实战项目（三选一）

| 项目 | 难度 | 涵盖技术点 |
|-----|------|-----------|
| 个人博客系统 | ⭐⭐ | CRUD、Markdown、分类标签 |

| 简易电商后台 | ⭐⭐⭐ | 商品/订单/库存、权限 |

#### 6.2 全栈协作流程

```
前端（React/Vue）  ←→  REST API  ←→  Spring Boot
                                          ↓
                                       MySQL
                                          ↓
                                        Redis
```

- 接口文档：Swagger / Knife4j
- 联调：前端 proxy 或后端 CORS
- 环境区分：dev / prod 配置

#### 6.3 部署基础

- 打包：`mvn package` 生成 JAR
- 服务器部署：Java -jar 运行
- Docker 容器化（入门）
- Nginx 反向代理（了解）

**实践任务**：

## 四、前端 vs Java 概念对照表

| 前端 (JS/TS) | Java | 说明 |
|-------------|------|------|
| `npm` / `yarn` | Maven / Gradle | 包管理与构建 |
| `package.json` | `pom.xml` / `build.gradle` | 项目配置 |
| `Array.map()` | `stream().map()` | 集合转换 |
| `Promise` | `CompletableFuture` | 异步编程 |
| `interface` (TS) | `interface` (Java) | 接口约束 |
| `class` | `class` | 类（Java 更严格） |
| `export / import` | `package / import` | 模块系统 |
| Express / Koa | Spring Boot | Web 框架 |
| MongoDB / Firebase | MySQL + Redis | 数据存储 |
| ESLint | Checkstyle / SpotBugs | 代码规范 |
| Jest / Vitest | JUnit / Mockito | 单元测试 |
| Vite dev server | spring-boot-devtools | 热重载 |

## 六、学习建议

1. **每天写代码**：看懂了 ≠ 会写，必须动手敲。
2. **善用前端经验**：学新概念时主动找 JS/TS 类比，降低认知负担。
3. **做笔记**：在本目录下按阶段建子文件夹，记录代码和心得。
4. **先广后深**：阶段 1~6 先走通全链路，再回头补深度。
5. **做项目驱动**：每完成一个阶段，用一个小项目串联知识点。
6. **阅读源码**：Spring Boot 学完后，试着读你项目里的代码，理解框架帮你做了什么。
