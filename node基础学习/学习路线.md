# Node.js 学习路线（前端工程师版）

> 面向有前端经验（HTML / CSS / JavaScript / 框架）的开发者，系统掌握 Node.js 后端开发能力。

---

## 一、学习前准备

### 1.1 心态与目标


| 前端已有能力                | 学 Node 时的迁移价值       |
| --------------------- | ------------------- |
| JavaScript 语法         | 直接复用，专注 Node 特有 API |
| Promise / async-await | Node 异步编程核心，无缝衔接    |
| npm / package.json    | 日常操作，加深工程化理解        |
| HTTP / REST API 调用    | 从「消费 API」到「提供 API」  |
| 构建工具（Vite/Webpack）    | 理解 Node 在工具链中的角色    |
| TypeScript            | 可渐进引入 Node 项目       |


**建议目标**：掌握 Node 核心模块与异步模型 → 能写 Express API → 理解工程化与部署 → 为全栈/Java 后端学习打基础。

### 1.2 环境搭建

- **Node.js**：安装 20 LTS（或 18 LTS）
- **包管理**：npm（自带）或 pnpm / yarn
- **编辑器**：Cursor / VS Code（你已有）
- **调试**：VS Code 断点调试、Chrome DevTools（`node --inspect`）

```bash
node -v    # v20.x.x
npm -v     # 10.x.x
```

## 三、各阶段详细内容

### 阶段 0：环境与 Node 认知（约 3~5 天）

**学习目标**：理解 Node 是什么、和浏览器的区别，能运行第一个脚本。


| 主题               | 要点                  | 前端类比                |
| ---------------- | ------------------- | ------------------- |
| Node 是什么         | V8 引擎 + 事件循环 + 内置模块 | 浏览器去掉 DOM，加上文件/网络能力 |
| REPL             | `node` 进入交互模式       | 浏览器 Console         |
| 运行脚本             | `node app.js`       | 无 bundler 直接跑 JS    |
| global / process | 全局对象、进程信息           | `window` / 无对应      |
| npm 初识           | 安装依赖、package.json   | 和前端项目完全一样           |


**实践任务**：

- [ ] 运行 `hello-world.js`
- [ ] 对比 `node-vs-browser.js` 输出，理解环境差异
- [ ] 用 `node -e "console.log(process.version)"` 查看版本

**本仓库 Demo**：`01-环境与基础/01-Node入门/`

---

### 阶段 1：模块系统 & 核心 API（约 1~2 周）

**学习目标**：掌握 CommonJS / ESM，熟练使用 fs、path、events。

#### 1.1 模块系统

- **CommonJS**：`require()` / `module.exports`（Node 传统，仍广泛使用）
- **ES Module**：`import` / `export`（`.mjs` 或 `"type": "module"`）
- `__dirname` / `__filename`（CJS 专有）
- `import.meta.url`（ESM 中获取路径）

> **对比前端**：Vite/Webpack 里的 `import` 在 Node 里需要配置才完全等价；原生 Node 默认 CJS。

#### 1.2 文件系统 fs

- 同步 vs 异步 API（`readFile` vs `readFileSync`）
- Promise 版：`fs/promises`
- 读写文本、JSON、目录操作

#### 1.3 路径 path & URL

- `path.join`、`path.resolve`、`path.extname`
- `fileURLToPath`（ESM 路径处理）
- `URL` 类解析请求地址

#### 1.4 事件 EventEmitter & Stream

- 发布订阅：`on` / `emit` / `once`
- Readable / Writable Stream
- 大文件处理、背压（backpressure）概念

**实践任务**：

- [ ] 用 fs 读写 JSON 配置文件
- [ ] 写一个 EventEmitter 简易事件总线
- [ ] 用 Stream 复制大文件

**本仓库 Demo**：`01-环境与基础/02-模块系统/`、`02-核心模块/`

---

### 阶段 2：异步编程深入（约 1 周）

**学习目标**：彻底理解 Node 异步模型，避免回调地狱。


| 模式          | 说明                       | 前端类比              |
| ----------- | ------------------------ | ----------------- |
| Callback    | `(err, data) => {}` 错误优先 | 老式 AJAX callback  |
| Promise     | `.then()` / `.catch()`   | 标准 Promise        |
| async/await | 同步写法处理异步                 | 完全一样              |
| Event Loop  | 宏任务 / 微任务执行顺序            | 浏览器 Event Loop 同源 |


**重点**：

- 错误处理：`try/catch` + `async/await`
- `Promise.all` / `Promise.allSettled` 并发控制
- 理解为什么 Node 适合 I/O 密集型

**实践任务**：

- [ ] 把回调版 fs 改写为 async/await
- [ ] 运行 `event-loop-demo.js`，观察输出顺序
- [ ] 并发读取多个文件并合并结果

**本仓库 Demo**：`03-异步编程/`

### 阶段 3：Web 服务 & Express（约 2~4 周）

**学习目标**：能独立搭建 RESTful API，这是你前端经验的最大优势区。

> Express 有独立子路线，详见 **[04-Web服务/Express学习路线.md](./04-Web服务/Express学习路线.md)**（8 步从入门到部署）。

#### 3.1 原生 http 模块（建议 2~3 天）

- 创建 Server、监听端口
- 解析 `req.url`、`req.method`
- 返回 JSON 响应、手动处理 CORS

> 理解原理后，Express 只是对 http 的封装。不要跳过这步。

**本仓库 Demo**：`04-Web服务/01-原生HTTP/`

#### 3.2 Express 框架（建议 2~3 周）

按子路线分 8 步推进，核心模块如下：

| 步骤 | 主题 | 要点 |
|-----|------|------|
| 1 | 基础 | `express()`、`app.listen`、最小路由 |
| 2 | 路由与请求 | `req.params` / `req.query` / `req.body`、`Router` 模块化 |
| 3 | **中间件** | 洋葱模型、`next()`、`express.json()`、自定义中间件 |
| 4 | RESTful 设计 | HTTP 方法语义、状态码、统一响应格式、CORS |
| 5 | 错误与校验 | 全局错误处理、`express-validator`、async 错误捕获 |
| 6 | 认证与上传 | JWT 中间件、`multer` 文件上传 |
| 7 | 项目结构 | routes / controllers / services 分层、nodemon |
| 8 | 测试与安全 | `supertest`、`helmet`、PM2 部署 |

**前端类比速查**：

| 前端 | Express |
|-----|---------|
| React Router | `express.Router` |
| Axios 拦截器 | `app.use` 中间件链 |
| 错误边界 | 全局 `(err, req, res, next)` 中间件 |
| `import.meta.env` | `process.env` + dotenv |

#### 3.3 前后端协作

- CORS 配置（开发 `*`，生产指定域名）
- 统一响应格式 `{ code, data, message }`
- 用 Postman / Apifox / 前端 fetch 联调
- OPTIONS 预检请求处理

**阶段 3 实践任务**：

- [ ] 原生 http 实现 `/api/hello`（`01-原生HTTP/`）
- [ ] 跑通 Express 入门 Demo，理解中间件顺序（`02-Express入门/`）
- [ ] 完成 Todo CRUD API，数据持久化到 JSON（`06-实践练习/todo-api/`）
- [ ] 用前端项目调用自己写的 API
- [ ] （进阶）JWT 登录 + 路由模块化重构

**本仓库 Demo**：`04-Web服务/`、`06-实践练习/todo-api/`

## 四、浏览器 vs Node 概念对照表


| 浏览器                      | Node.js              | 说明                |
| ------------------------ | -------------------- | ----------------- |
| `window`                 | `globalThis`         | 全局对象              |
| `document`               | —                    | Node 无 DOM        |
| `localStorage`           | `fs` 写文件 / 数据库       | 持久化方式不同           |
| `fetch('/api')`          | `fetch` 或 Express 路由 | Node 18+ 内置 fetch |
| `<script type="module">` | `"type": "module"`   | ESM 支持            |
| Vite dev server          | `node server.js`     | 开发服务器             |
| `npm run dev`            | `npm run dev`        | 完全一样              |
| Service Worker           | —                    | Node 无此概念         |
| WebSocket 客户端            | `ws` 模块做服务端          | 角色反转              |

## 六、学习建议

1. **JS 语法不用重学**：把时间花在 Node API 和工程化上。
2. **先跑通再深入**：先让 Demo 跑起来，再读源码理解原理。
3. **对比浏览器 Event Loop**：阶段 2 是分水岭，理解异步才算入门 Node。
4. **做 API 项目**：你比纯后端更懂前端要什么格式的接口——这是优势。
5. **和 Java 路线配合**：Node 做 BFF / 工具链，Java 做核心业务，是很多团队的真实架构。
